# QuickBite Backend

QuickBite is a food ordering application backend developed using Java, Spring Boot, Spring Data JPA, and MySQL.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- REST APIs

## Features
- User Signup and Login
- Food Listing
- Add food items to Cart
- Update Cart Quantity
- Remove Cart Items
- Place Orders
- View Order Details

## Backend API
```text
http://localhost:8080
```

## Database
- Database Name: `quickbite_db`
- Database: MySQL

## How to Run
1. Clone this repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Configure MySQL database credentials.
4. Set the `DB_PASSWORD` environment variable.
5. Run the Spring Boot application.
